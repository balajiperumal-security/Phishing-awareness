# Task 2 — Phishing Awareness

Includes a local URL warning-sign checker, awareness guide, and mini quiz. The checker uses only Python's standard library and makes no network requests.

Run:
```bash
cd Task2_Phishing_Awareness
python3 phishing_checker.py
```
Or:
```bash
python3 phishing_checker.py https://example.com
```
Use harmless examples. Do not visit suspicious URLs. This is not a definitive phishing detector.
